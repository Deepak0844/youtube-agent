# Cartoon scenes: the yt-toon kit

GENERATED by scripts/sync-toon-dts.ts. Cartoon-shorts' own puppets, set pieces and looks (MIT), as React components. A cartoon scene file
imports them with named imports, one module per file below. Times are beat marks (B5, B5e, B5%60, B5+.3), scene ids (hook, hooke, hook+1) or seconds.
